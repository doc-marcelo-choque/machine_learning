# Machine Learning - Ejemplos Prácticos

Repositorio de ejemplos prácticos de **Machine Learning con Python**, orientado al aprendizaje y aplicación de algoritmos de aprendizaje automático.

## Finalidad

Este repositorio tiene fines **educativos y académicos**, con ejemplos desarrollados para facilitar la comprensión de los algoritmos de Machine Learning y su aplicación en problemas prácticos.

## Contenido

- **Clasificación:** Árboles de decisión, regresión logística y Random Forest.
- **Regresión:** Regresión lineal y modelos predictivos.
- **Clustering:** K-Means y aprendizaje no supervisado.
- **Evaluación de modelos:** Accuracy, precisión, recall, F1-score y matriz de confusión.
- **Predicciones:** Aplicación de modelos entrenados a nuevos datos.

## Tecnologías

- Python
- Pandas y NumPy
- Scikit-learn
- Matplotlib y Seaborn
- Jupyter Notebook

## Instalación

Clonar el repositorio:

```bash
git clone https://github.com/doc-marcelo-choque/machine_learning.git
```

Instalar las dependencias si es necesario:

```bash
pip install -r requirements.txt
```
