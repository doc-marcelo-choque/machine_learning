
# Prompt 01: Regresión lineal simple

Crear el notebook `notebooks/regresion_lineal_ecommerce.ipynb`
utilizando el archivo Excel ubicado en `data/`.

## Objetivo
Predecir el número de ventas de una página web
a partir del número de visitantes.

## Actividades
1. Importar las librerías necesarias.
2. Cargar el Excel y explorar los datos.
3. Mostrar estadísticas descriptivas y valores nulos.
4. Crear un gráfico de dispersión.
5. Calcular la correlación entre Visitantes y Ventas.
6. Separar los datos en entrenamiento 80% y prueba 20%, respetando el orden cronológico.
7. Entrenar un modelo LinearRegression.
8. Mostrar la ecuación de regresión y su gráfica.
9. Evaluar el modelo con MAE, RMSE y R².
10. Graficar los valores reales frente a los estimados.
11. Predecir ventas para 500, 800 y 1200 visitantes.

## Requisitos
- X = Visitantes.
- Y = Ventas.
- Utilizar pandas, matplotlib y scikit-learn.
- Explicar cada paso con Markdown.
- Mantener el código sencillo y educativo.
- Ejecutar y verificar el notebook.
