# AGENTS.md

## Objetivo
Desarrollar proyectos educativos de Machine Learning con Python.

## Reglas generales
- Utilizar código sencillo, legible y organizado.
- Priorizar pandas, matplotlib y scikit-learn.
- Trabajar con notebooks Jupyter (.ipynb).
- Explicar cada etapa mediante celdas Markdown.
- Escribir explicaciones en tercera persona.
- Utilizar comentarios técnicos breves.
- Evitar funciones y clases innecesarias.
- No modificar los datasets originales.
- Utilizar rutas relativas al proyecto.
- Mantener y ampliar el código existente.
- Verificar que el notebook funcione correctamente.

## Estructura
- data/: datasets.
- notebooks/: notebooks de Machine Learning.
- resultados/: gráficos, métricas y predicciones.
- prompts/: instrucciones para el agente.
